# Tecnología e implementación

Aquí vivirá el código de la plataforma. Se construye con **desarrollo guiado por especificaciones** usando Spec Kit: ningún código se escribe sin su especificación, plan y tareas en la carpeta `specs/`.

| Carpeta | Contenido | Estado |
|---|---|---|
| `backend/` | API NestJS con TypeScript (monolito modular). | Se crea con la funcionalidad 001. |
| `frontend/` | Aplicación web React + Vite. | Se crea con la funcionalidad 001. |
| `ejemplo-clean-architecture/` | Esqueleto vacío del módulo Contrataciones según el diseño interno. | Se reemplaza por el módulo real en la funcionalidad 004. |

El stack está definido en ADR-013 y los principios que debe cumplir el código están en la constitución (`.specify/memory/constitution.md`).
